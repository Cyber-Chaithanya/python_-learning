## 💻 Getting Started

### 1. Clone this repository

```bash
git clone https://github.com/Cyber-Chaithanya/python_-learning.git
```

### 2. Open the project folder

```bash
cd python_-learning
```

### 3. Run a Python program

```bash
python python/programs/program-1.py
```

Make sure Python 3 is installed on your computer.

**Note:** Some programs may require different input values or additional setup.
